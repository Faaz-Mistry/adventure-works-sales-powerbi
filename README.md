# Adventure Works Sales Overview

**Tool:** Power BI

![Preview](preview.jpg)

Global sales, profitability and customer insights on the Adventure Works sample data.

## Highlights
- Sales amount and product standard cost by quarter
- Standard cost by sales territory, order quantity by gender
- Tax by month and freight by country on maps
